Comments in Python
What are Comments?
A comment is a line of text in a Python program that is ignored by the Python interpreter.
Comments are used to:
Explain the code
Improve readability
Add notes for developers
Temporarily disable code during testing
-----------------------------------------------------------------------------------------
Types of Comments
Python mainly uses two types of comments.
Single-line Comment
Multi-line Comment (using triple-quoted strings as documentation or multi-line text)

1. Single-Line Comment
A single-line comment starts with the hash (#) symbol.
Syntax
# This is a comment
Example
# Printing a welcome message
print("Welcome to Python")
Output
Welcome to Python

Multiple Single-Line Comments
# Student Information
# Name : Rahul
# Course : Python
# Batch : PFS-101

print("Student Registered")
------------------------------------------------------------------------------------------
2. Multi-Line Comment
Python does not have a special multi-line comment syntax.
However, programmers often use triple-quoted strings ('''...''' or """...""") as documentation strings (docstrings) or for multi-line text.
Using Triple Double Quotes
"""
This program
demonstrates
multi-line text.
"""

print("Python")
Using Triple Single Quotes
'''
This is another
multi-line text block.
'''

print("Hello")
Note: According to the Python documentation, triple-quoted strings are actually string literals. When placed at the beginning of a module, function, or class, they become docstrings.

Swapping Two Variables
Swapping means exchanging the values of two variables.
Suppose
a = 10
b = 20
After swapping
a = 20
b = 10
-----------------------------------------------------------------------------------------
Method 1: Using a Third Variable
Algorithm
temp = a
a = b
b = temp
Example
a = 10
b = 20

temp = a
a = b
b = temp

print(a, b)
Output
20 10

Memory Representation
Before Swapping
a → 10
b → 20
After Swapping
a → 20
b → 10

Method 2: Without Using a Third Variable (Arithmetic Method)
Algorithm
a = a + b
b = a - b
a = a - b
Example
a = 10
b = 20

a = a + b
b = a - b
a = a - b

print(a, b)
Output
20 10
Step-by-Step
Step
a
b
Initial
10
20
a = a+b
30
20
b = a-b
30
10
a = a-b
20
10


Method 3: Pythonic Swapping (Recommended)
Python provides a simple way to swap variables without using a third variable.
Syntax
a, b = b, a
Example
a = 10
b = 20

a, b = b, a

print(a, b)
Output
20 10
This is the recommended and most commonly used method in Python.

Tuple
A tuple is a collection of ordered items enclosed in parentheses ().
Syntax
tuple_name = (item1, item2, item3)
Example

Tuple Properties
Ordered
Indexed
Immutable
Allows duplicate values
Example
colors = ("Red", "Blue", "Green")

print(colors[1])
Output
Blue

A single-item tuple is a common beginner mistake in Python.
Incorrect Example
student = ("Raju")

print(type(student))
Output
<class 'str'>
Explanation:
Python treats ("Raju") as just a string inside parentheses.
It is not a tuple.

Correct Example (Single Item Tuple)
student = ("Raju",)

print(student)
print(type(student))
Output
('Raju',)
<class 'tuple'>
The comma (,) tells Python that this is a tuple.

More Examples
Integer
number = (10,)

print(number)
print(type(number))
Output
(10,)
<class 'tuple'>

Float
price = (99.5,)

print(price)
print(type(price))
Output
(99.5,)
<class 'tuple'>

Boolean
status = (True,)

print(status)
print(type(status))
Output
(True,)
<class 'tuple'>

Why is the comma required?
Python identifies a tuple by the comma, not by the parentheses.
x = (5)
print(type(x))
Output
<class 'int'>

x = (5,)
print(type(x))
Output
<class 'tuple'>

Interview Question
Q: How do you create a tuple with only one element?
Answer:
A single-item tuple must end with a comma.
student = ("Raju",)
Without the comma, Python treats it as a normal value enclosed in parentheses, not as a tuple.

Range
A range object generates a sequence of numbers.
It is commonly used with loops.

Syntax
One Argument
range(stop)
Example
range(5)
Sequence
0 1 2 3 4

Two Arguments
range(start, stop)
Example
range(2, 8)
Sequence
2 3 4 5 6 7

Three Arguments
range(start, stop, step)
Example
range(0, 10, 2)
Sequence
0 2 4 6 8

Printing a Range
print(list(range(5)))
Output
[0, 1, 2, 3, 4]

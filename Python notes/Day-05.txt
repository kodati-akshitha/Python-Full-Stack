What are Operators?
An operator is a symbol or keyword that performs an operation on one or more operands (values or variables).
Example
a = 10
b = 20

print(a + b)
Here,
+ → Operator
10, 20 → Operands
Output
30

Interview Questions
1. What is the difference between / and //?
/ returns the quotient as a float.
// returns the quotient after floor division (without the fractional part).
Example:
print(10 / 3)   # 3.3333333333333335
print(10 // 3)  # 3

2. What is the difference between % and //?
% returns the remainder.
// returns the quotient after floor division.

3. What is the difference between == and is?
== compares whether two values are equal.
is checks whether two variables refer to the same object in memory.

4. Why is is None preferred over == None?
None is a singleton object in Python. The recommended way to check for it is:
if value is None:
    print("No value")
This follows the recommendation in the Python style guide (PEP 8).

5. Where are bitwise operators commonly used?
Device drivers
Embedded systems
Networking protocols
Cryptography
Permission and flag management
Performance-critical low-level programming
